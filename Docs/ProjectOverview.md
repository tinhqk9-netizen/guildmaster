## Cấu Trúc Thư Mục
Dự án được tổ chức theo chuẩn Modular/Sạch sẽ:
- `Assets/_Game/Art`: Chứa toàn bộ hình ảnh phân loại theo chức năng (Areas, Backgrounds, Characters, UI...).
- `Assets/_Game/Audio`: Âm thanh game.
- `Assets/_Game/Data`: Dữ liệu (Definitions & Runtime).
- `Assets/_Game/Prefabs`: Cấu trúc Prefab cho UI, Cards, Dialogs.
- `Assets/_Game/Scenes`: Các scene cốt lõi (Boot, Main).
- `Assets/_Game/Scripts`: Mã nguồn phân chia rõ ràng theo domain (Core, Combat, UI, Economy...).
- `Assets/_Game/Settings`: Các cấu hình game (URP, Input...).
- `Assets/StreamingAssets/GameData`: Dữ liệu thô (nếu có).
