# MVP Data Set

Dữ liệu cứng được chọn lọc từ decode cho Phase MVP.

## 1. Items (10 vật phẩm cơ bản)
*Lý do:* Kiểm tra vòng lặp chế đồ, đánh quái rớt đồ cơ bản.
- \plant_fiber\, \east_pelt\, \copper_ore\, \wood\ (Nguyên liệu thô)
- \cloth\, \leather\, \copper_ingot\ (Vật liệu đã chế)
- \copper_sword\, \copper_armor\, \wooden_buckler\ (Trang bị cơ bản)

## 2. Adventurers (3 Lớp nhân vật cơ bản)
*Lý do:* 3 class cận chiến/phép cơ bản để test combat.
- \dept\ (Mage)
- \lchemist\ (Support/Magic)
- \pprentice\ (Healer)

## 3. Enemies (5 Quái vật đầu game)
*Lý do:* Rớt các nguyên liệu thô phía trên.
- \green_slime\, \oar\, \lpha_wolf\, \andit\, \skeleton\
*(Ghi chú: Cần check lại xem các tên này có chính xác trong decode không - OPTIONAL_PENDING_AUDIT)*

## 4. Dungeons (1 Hầm ngục)
- \arren_wastelands\ (Thấy xuất hiện trong danh sách)
