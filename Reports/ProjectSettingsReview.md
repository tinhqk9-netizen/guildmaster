# Báo Cáo: Project Settings Review

## 1. Color Space
- Đang sử dụng: Linear (`m_ActiveColorSpace: 1`)
- Đánh giá: Chuẩn cho các project Unity hiện đại (URP).

## 2. Input System
- Đang sử dụng: Active Input Handler 1 (Có package `com.unity.inputsystem` cài đặt).
- Đánh giá: Đang dùng Input System mới.

## 3. Graphics & Quality
- Render Pipeline: URP (Universal Render Pipeline).
- Setting cụ thể sẽ phụ thuộc vào URP Asset trong project.

## 4. Resolution & Player Settings
- Default Screen Width/Height: 1920x1080 (Stand-alone).
- Screen Orientation: Đã chuyển sang **Portrait** (`defaultScreenOrientation: 0`).
- Company Name: DefaultCompany
- Product Name: Rebuild_GuildMaster

## 5. Build Settings
- Nền tảng đích: Android (Yêu cầu ở Task 04, đã note lại).
- Các Scene trong Build: `Boot.unity` và `Main.unity` (đã được tạo ở Task 03).
