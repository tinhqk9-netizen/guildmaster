# 09. Batch 1 UI Blocker & Layout Audit Register (Đã Cập Nhật Thực Tế)

Báo cáo kiểm thử giao diện người dùng về các lỗi tràn chữ (Text Wrapping), chồng chéo Layout (Overlap) và giới hạn RectTransform trên các màn hình hoạt động chính.

## Chi Tiết Các Lỗi Tràn Chữ & Đề Xuất Khắc Phục Layout

| Màn Hình UI | Vấn Đề Layout Thực Tế | Ảnh Hưởng Hiển Thị | Cơ Chế Text Component | Đề Xuất Sửa Đổi RectTransform & Component Settings |
| :--- | :--- | :--- | :--- | :--- |
| **Craft Screen** | - RectTransform width của card công thức (Recipe Card) quá hẹp.<br>- Text mô tả nguyên liệu bị xuống dòng không chính xác. | Chữ bị bẻ đôi ngớ ngẩn (ví dụ: 'Works hop' thay vì 'Workshop', 'Wood en' thay vì 'Wooden'). | Legacy `UnityEngine.UI.Text` set Horizontal Wrap Mode = `Wrap`. | 1. Đổi `Horizontal Wrap Mode` của UI Text sang `Overflow` đối với các nhãn 1 dòng (Button label).<br>2. Bật tính năng `Best Fit` trên Text Component, đặt Min Size = 10, Max Size = 16 để tự giảm size khi chuỗi quá dài.<br>3. Tăng Width tối thiểu của Recipe Card từ 100px lên 135px. |
| **Dungeon Screen**| - Ô thông tin Dungeon Mô tả Dungeon và Danh sách vật phẩm rớt bị giới hạn chiều cao.<br>- Scrollview không tự động cập nhật size. | Chữ bị bẻ đôi (ví dụ: 'Dung eons' thay vì 'Dungeons'). Chữ mô tả bị cắt đứt nửa chừng hoặc chống lấn vào nút Start. | Legacy `UnityEngine.UI.Text` thiếu Container co dãn động. | 1. Thêm component `ContentSizeFitter` vào Object chứa Text mô tả, đặt `Vertical Fit` = `Preferred Size`.<br>2. Kèm theo component `VerticalLayoutGroup` trên Parent Container để tự đẩy các layout phía dưới (như Button Start) đi xuống khi text mô tả dài ra, tránh Overlap.<br>3. Chuyển Horizontal Wrap Mode của nút "Dungeons" thành `Overflow`. |
| **Inventory Screen**| - Các ô Grid chứa vật phẩm (Item Slots) có RectTransform cố định 64x64px.<br>- Text số lượng (Stack Size) và Tên vật phẩm bị tràn ra ngoài viền. | Số lượng vật phẩm che mất icon. Tên vật phẩm dài bị tràn xuống dòng thứ 2 chèn vào các ô Grid bên dưới. | Legacy `UnityEngine.UI.Text` không tự Scale Font Size. | 1. Bật `Best Fit` trên Text hiển thị Stack Size ở góc dưới ô item (Min Size = 8, Max Size = 12).<br>2. Đặt Anchor của Stack Text sát góc phải và căn lề Right.<br>3. Mở rộng chiều cao cell card chứa tên vật phẩm hoặc giới hạn Text hiển thị tối đa 2 dòng, phần thừa tự cắt (truncation). |
| **Quest Screen** | - Thẻ nhiệm vụ (Quest Card) hiển thị tiến độ và tên Quest bị ép chật hẹp. | Progress `'12/15 [Completed] ✓'` bị bẻ xuống dòng lung tung do Card Width hẹp. | Legacy `UnityEngine.UI.Text` không co dãn. | 1. Sử dụng Layout Element trên Quest Card, đặt `Preferred Width` tối thiểu là 150px.<br>2. Đổi Horizontal Wrap Mode của dòng Progress sang `Overflow` để đảm bảo chuỗi trạng thái nằm trọn vẹn trên một dòng. |
