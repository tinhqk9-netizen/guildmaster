## Điểm rủi ro cao nhất
1. **`FormulaService.CalculateDamage_ManualPortRequired()` là stub rỗng** → không có công thức damage nào được port. Mọi thứ liên quan combat đều đứng sau rào này.
2. **`CharacterService.GetTotalStat()` hardcode `levelMultiplier = 1.0f`** → chỉ số nhân vật hiện **không đúng** so với decode. Đây là chỗ dễ bị hiểu nhầm là "đã xong" vì code chạy không lỗi.
3. **`SaveData` thiếu `lastAccess`** → offline progress về mặt kỹ thuật **chưa thể hoạt động**.
4. **`Area.java` 3164 dòng vs `DungeonService` 202 + `CombatService` 139 dòng** → phần nặng nhất của game mới port khoảng **10%**.
5. **Doctrine system hoàn toàn vắng mặt** — ảnh hưởng cả combat (damage modifier) lẫn quest (`setupDoctrineAmounts`).
